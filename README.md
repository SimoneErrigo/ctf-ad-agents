# ctf-ad-agents

This project is an early-stage prototype for an agentic AI system designed to support Capture The Flag competitions, with a focus on Attack & Defense scenarios.

The goal is to explore how multiple AI agents can collaborate to analyze game events, monitor services, reason about attacks and defenses, and assist teams through an orchestrated workflow.

At this stage, the repository only contains the initial project structure and documentation. The architecture, implementation details, and core components will be developed progressively.
